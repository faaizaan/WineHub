# WineHub 🍷

## Descrizione

WineHub è una web application full-stack dedicata alla gestione e alla vendita di vini.
Gli utenti possono registrarsi, effettuare il login, consultare il catalogo dei vini, aggiungere prodotti ai preferiti, lasciare recensioni ed effettuare ordini.
I seller possono creare, modificare ed eliminare i propri vini, mentre gli amministratori possono gestire il catalogo.

## Avvio del Progetto

### Backend

1. Configurare PostgreSQL. 
2. Inserire le credenziali del database nel file `application.properties`.
3. Avviare la classe principale `WineHubApplication`.

Backend disponibile su:

http://localhost:1312

### Frontend

Installare le dipendenze:

npm install

Avviare il progetto:

npm run dev

Frontend disponibile su:

http://localhost:5173
