# WineHub

descrizione:
Web app enoteca dove gli utenti possono registrarsi, gestire e visualizzare vini.

🎯 Obiettivo
Realizzare un'app full-stack con autenticazione e CRUD completo.


⚙️ Funzionalità (v1)
- Login / Registrazione
- Lista vini
- Dettaglio vino
- CRUD vini
- Categorie (rosso, bianco, ecc.)


🚀 Future features (v2)
- Carrello
- Acquisto simulato


⭐ Future features (v3)
- Filtri avanzati (prezzo, categoria)
- Sistema preferiti
- Recensioni vini


- Backend: Spring Boot
- Frontend: React
- Database: PostgreSQL
